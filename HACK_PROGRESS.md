# HeartGold hack – progress notes

Branch `hgss-hack` on jicksatx/heartgold-hack (fork of BluRosie/hg-engine).
Base ROM: US English HeartGold (game code IPKE). Personal use only.

## Plan (priority order) and status
1. National Dex + Running Shoes at New Game — DONE (`NEW_GAME_START_BONUSES`, src/save.c)
2. Goldenrod evolution items (3F) + Mints (4F, replacing vitamins) — DONE (src/field/mart.c). Celadon 5F vitamins also → Mints. Mints 4,000; Razor Claw / Chipped Pot 3,000.
3. Running indoors (vanilla HGSS already allows), infinite TMs (`REUSABLE_TMS`), remove EVs — DONE (`REMOVE_EVS`, bytereplacement). EV berries kept as friendship berries (text updated).
4. Impossible evolutions — DONE. Trade/trade-item evos → use item (Linking Cord, Sachet, Whipped Dream, held items made usable). Levels: Milcery 25, Poltchageist 28, Gimmighoul 40, Bisharp 50, Stantler 30, Pawmo 32, Bramblin 30, Rellor 30, Primeape 35, Dipplin→Hydrapple 40.
5. Gens 1–9 + Fairy — DONE (audit). Missing Gen 9 battle sprites (9) and follower sprites (30) converted from pokeemerald-expansion (scripts/hack/). HeightTable recomputed for Gen 5+.
   - Extra: 8 abilities and 30 moves implemented (see git log). Skipped: Opportunist, Ball Fetch, Symbiosis, Embody Aspect; 29 moves still unimplemented (doubles/field effects).
6. Remove Dynamax/Gigantamax, Z-moves, Tera leftovers — DONE. Engine never activates any of them (battle steps are empty stubs, flags never set); no gimmick moves in learnsets, items in shops/wild held items, or trainer data. Fixed Metronome/Copycat being able to call G-Max moves and unimplemented moves. Terapagos Tera Shift form change kept (ability, not Terastallization).
7. Mega Stone shop — DONE. Goldenrod Radio Tower 1F "Ben fan" NPC (data/scr_seq/scr_seq_00029_D23R0101.s, text data/text/065.txt). First talk gives Key Stone + sets FLAG_MEGA_EVOLUTION_ENABLED, then sells all 92 Mega Stones at 10,000 each via new special mart index 30 (expanded table sSpecialMartTable in src/field/mart.c, repointed at 0x02048190).
8. Level caps — DONE. IMPLEMENT_LEVEL_CAP + LEVEL_CAP_FROM_BADGES (GetLevelCapFromBadges in src/pokemon.c): Johto 13/17/19/25, 35 for Chuck/Jasmine/Pryce, 41 Clair, 50 Elite Four; Kanto by badge count 50,53,54,54,55,56,59,60; 88 for Red. Rare Candies capped. Daycare not capped (vanilla code).
9. Move Relearner — DONE. Shared std script 2074 (commonscript entry 074, text 040.txt 121-127). One flavor NPC in each gym town Pokémon Center calls it (data/scr_seq/scr_seq_00xxx_T??PC0101.s): Violet, Azalea, Goldenrod, Ecruteak, Cianwood, Olivine, Mahogany, Blackthorn, Pewter, Cerulean, Vermilion, Celadon, Fuchsia, Saffron, Cinnabar, Viridian. 500 charged only when a move is learned.
10. Starter randomizer — DONE. RANDOMIZE_STARTERS, src/randomizer.c. Seed made once per new game (first use), stored in vars 0x4164/0x4165. One Grass/Fire/Water line each from 9 per type (Gens 1–9). Silver's Johto starter lines remapped stage-for-stage in src/field/enemy_party.c. Elm's selection text names the type (data/text/190.txt). Not updated: friend's Pokégear flavor lines naming Johto starters (text 662/663).
11. Area randomizer — DONE. RANDOMIZE_WILD_ENCOUNTERS: WildEncounters_ReadFromNarc replaced (src/randomizer.c) so each map's table is remapped as it loads (grass morning/day/night, surf, old/good/super rod, rock smash, swarms, radio sounds). Per area (encounter bank) + original species -> pool species within ~10% BST (widened to >=8 choices), same seed as starters. Pool generated by scripts/hack/gen_randomizer_pool.py into src/randomizer_pool.c (833 species; excludes all starter lines, legendaries, mythicals, sub-legends, UBs, 6 legendary Paradox). Not randomized: headbutt trees, Bug Contest, Safari Zone, gifts/statics/roamers; regional forms not in pool yet.
