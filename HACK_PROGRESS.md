# Glorious Gold (HeartGold hack) – progress notes

Branch `hgss-hack` on jicksatx/heartgold-hack (fork of BluRosie/hg-engine).
Base ROM: US English HeartGold (game code IPKE). Personal use only.

Name: **Glorious Gold**. Title-screen logo redrawn (rawdata/title_logo = demo/title/titledemo.narc members 0 and 3, made with scripts/hack/title_logo/), heart ornament removed; DS menu banner renamed by scripts/hack/patch_banner.py after the ROM is packed.
